## Designer's note

Shown on first hold, then behind the ? in the listening header. Each row is tappable — it starts listening pre-biased to that intent. The grammar is intent + entities in any order, any language mix; dates like "next Thursday evening" and teeth like "lower right six / 46" both resolve. Consultation recording deliberately stays out — that's the orb's tap, protected from misfires.
