## Designer's note

History is a spine of Odo moods: happy tooth = completed treatment, calm = routine visit, red node = permanent medical fact (rides the timeline forever, styled like the verification rail). On open the spine draws downward 350 ms, cards slide in staggered 45 ms, nodes pop last. Each card is a mini-bento: procedure, tooth, fee, doctor. Taps: card → visit record · procedure name → case detail · fee chip → billing tab · Filter → by tooth / treatment / doctor.
