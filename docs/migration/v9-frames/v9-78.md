## Designer's note

What the mic orb is: the fastest path to the app's core act — dictating. Tap = context action: patient in chair → start/continue recording (13); on Consult → record; anywhere else → jump to Consult. Hold = this menu, one thumb, no navigation: consultation, patient, booking, lab case, or "find Anand Kumar". First item always names who it will record — no accidental recordings.
