## Designer's note

New system rule: a lone number never gets a bento tile — it gets a 46px stat pill (number + label, tinted by state). Frees ~90px of screen and reads faster. Applied everywhere counts appear: Lab, Outstanding header, patient stat strip. Tiles are reserved for content with structure (money + breakdown, warnings, dates).
