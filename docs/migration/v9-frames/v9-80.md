## Designer's note

Two tap zones per row, always: the bold name opens the patient record; the row body opens the object (payment → billing entry, LB-113 → lab case, reply → thread, overdue → follow-ups). Unread = lime dot. Payment + lab pings also badge the tab icons; badges clear on visit.
